How to flash

  1. Select your board type above
  2. Connect the board to this computer via USB
  3. Click Install Firmware
  4. Select the serial port when prompted
  5. Wait for the flash to complete (~30 seconds)
  6. Open the Pulsar Android app to connect via BLE
